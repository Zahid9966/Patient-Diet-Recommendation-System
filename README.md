# 🩺 Patient Diet Recommendation System

A Streamlit web app that takes a patient's basic details and medical condition and uses Google's Gemini model, through LangChain, to suggest restaurants, breakfast and dinner items, and workout activities that suit them. Every submitted record and its recommendation is saved to a local SQLite database.

## 🚀 What it does

You fill in ten fields:

| Field | Notes |
|---|---|
| Age, Weight (kg), Height (cm) | free text |
| Gender | Male / Female |
| Veg or Non-Veg | diet preference |
| Disease | the patient's condition |
| Region, State / City | used to suggest local restaurants |
| Allergics | allergies (enter `None` if there are none) |
| Food Type | free text |

All ten fields are required. After you click **Get Recommendations**, the app asks Gemini for:

- 6 restaurants
- 6 breakfast items
- 5 dinner items
- 6 workout activities

The answer is shown on the page and saved together with the inputs and a timestamp.

## 🛠️ Tech stack

- **Python**
- **Streamlit**: the web interface
- **LangChain**: builds the prompt and calls the model
- **Google Generative AI (Gemini)**: generates the recommendation (`gemini-1.5-pro`)
- **SQLite**: local storage of records (`diet_system.db`)

## ▶️ How to run

1. Install the dependencies

```bash
pip install -r requirements.txt
```

2. Add your API key

Create a key in [Google AI Studio](https://aistudio.google.com/) and provide it in **one** of these ways (checked in this order):

- an environment variable: `export GOOGLE_API_KEY="your_key_here"`
- a `.env` file next to `app.py` containing `GOOGLE_API_KEY=your_key_here` (the file is git-ignored)
- a Streamlit secret named `GOOGLE_API_KEY` (for example on Streamlit Community Cloud: Settings → Secrets)

Never commit your key. If the key is missing, the app shows an error instead of starting.

3. Start the app

```bash
streamlit run app.py
```

## 🤖 How the AI works

```
form details  →  LangChain prompt template  →  Gemini  →  recommendation shown on the page and saved to SQLite
```

The model is called with a temperature of 0.9 and a limit of 2048 output tokens. The app does not calculate BMI or calories itself, and it does not train or use any machine-learning model of its own: all suggestions come from the language model's answer to the prompt.

## 🔒 Data and privacy

- Each submitted record is stored in plain text in a local SQLite file, `diet_system.db`, next to `app.py`. The file is git-ignored; keep it that way and do not publish or share it, because it contains health information.
- The patient details you enter are sent to Google's Gemini API to generate the recommendation.

## ⚠️ Notes and limitations

- **Not medical advice.** The recommendations are generated by an AI model and can be wrong or unsuitable. A qualified clinician or dietitian should review them before anyone acts on them.
- Restaurant suggestions come from the model, not from a live restaurant database, so names and availability may be inaccurate.
- The model name in `app.py` is `gemini-1.5-pro`. Google retires older model names over time, so if the app reports a model error, update the name to a current Gemini model.
- There is no login: anyone who can open the app can use it, and every request uses your Google API quota. Do not expose a deployed copy publicly without adding access control.
